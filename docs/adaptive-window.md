# Подбор слов: скользящее окно

Текущая реализация от 2026-11-02. Старые `adaptive-review-algorithm.md` и
`adaptive-review-v2.md` описывают предыдущие варианты; календарный SRS остаётся
отдельным режимом.

## Режимы и данные

Обычная тренировка по умолчанию равномерная для любого источника слов.
Адаптивная выбирается отдельной кнопкой перед стартом. Режим сохраняется в
самой сессии, и во время тренировки переключателей нет.

Адаптивная берёт **все доступные «Мои слова»**, включая помеченные выученными,
разговорные и слова без JLPT. Старые фильтры, лимиты и исключения из обычного
экрана настройки на неё не действуют. Явно скрытые/удалённые слова отсутствуют;
во время сессии остаётся возможность вручную исключить слово.

Для каждой карточки в `vocab.stats[id].wordPractice` хранятся сила запоминания,
число ответов, текущая серия, число провалов и дата последнего ответа. Эти данные
обновляются **во всех режимах слов**, входят в обычное сохранение аккаунта и
резервные копии. Старый mastery используется как осторожная начальная оценка
с потолком 0.7. Существующая статистика и календарная модель памяти сохраняются.

Сила — внутренняя оценка для подбора, а не измеренная вероятность правильного
ответа. Коэффициенты выбраны под проверяемые свойства нагрузки и продвижения;
их эмпирическая оптимальность для конкретного пользователя не установлена.

## Оценка знания

Начальная сила неизвестного слова: `s = 0.15`. Перед ответом или сортировкой
оценка уменьшается с возрастом последнего ответа:

```
s_effective = s * 2^(-days_since_answer / 30)
correct: s_next = s_effective + 0.30 * (1 - s_effective)
wrong / hint: s_next = max(0, s_effective - (0.18 + 0.38 * s_effective))
```

После четырёх верных ответов новое слово имеет около 0.796. При провале слово
с силой 0.95 теряет 0.541, а новое — 0.15: забывание знакомого слова штрафуется
существенно сильнее. Подсказка, «Не помню», восстановление после неверной попытки
и пропуск без ответа в адаптивной сессии не дают прироста знания. Медленный
правильный ответ засчитывается: скорость сама по себе не блокирует продвижение.

Показ карточки ничего не добавляет к знанию. Возврат по истории тоже не добавляет
ответы. Один завершённый раунд записывается один раз. На телефоне без ввода
пользователь явно нажимает «Помню»; после подсказки это всё равно провал.

## Подбор и расширение окна

1. При старте строится стабильный порядок от самой низкой эффективной силы к
   высокой. При равенстве сохраняется исходный порядок словаря.
2. Активная группа содержит максимум **5 слов** независимо от размера словаря.
   Сначала тренируются эти слова; полного первого прохода по словарю нет.
3. Внутри группы выбирается самое просроченное слово; затем учитывается давность
   показа и исходный порядок. Случайных весов и случайной очереди ошибок нет.
4. Слово освобождает место следующему, когда сила достигла **0.72** и есть
   **3 последовательных верных ответа в этой сессии**. Новому слову практически
   нужны четыре верных ответа; старое знание требует повторного подтверждения.
5. Освобождённое слово остаётся в очереди повторения. Начальный интервал —
   **12 показов**, дальше **24, 48, 96, 160**; потолок предотвращает исчезновение.
   Провал сокращает интервал до **4 показов** и сбрасывает серию, затем интервалы
   снова постепенно растут. Интервалы — желаемые сроки: нагрузка и очередь могут
   отложить повтор, а на маленьком наборе повтор может произойти раньше.
6. При наличии хотя бы двух активных слов очередь пройденных получает максимум
   **один показ из четырёх**. Просроченные слова выбираются по самому раннему
   сроку, поэтому успешные/неуспешные старые карточки не вытесняют всю группу и
   не исчезают навсегда. Когда новых/активных слов больше нет, сессия продолжает
   повторять введённые слова без искусственной остановки.

Желаемый интервал активного слова после успеха — 5 показов, после ошибки — 3.
Это приоритеты очереди, а не виртуальные скачки времени. Немедленный повтор
исключается, когда доступны хотя бы две карточки. На словаре из одного слова
повтор неизбежен; на конце маленького окна допускается дополнительный старый
повтор, чтобы не повторять единственного активного ученика подряд.

## Защита от застревания

Если слово не освободило место за **8 ответов** в активной группе, оно переходит
на повторение без отметки «выучено». Следующее слово занимает освободившийся
слот. После ошибки отложенное слово снова доступно через четыре показа, но
ограничение доли повторов защищает основной поток. Поэтому даже пять слов,
на которые пользователь всегда отвечает неверно, не блокируют остальной словарь.

Курсор ввода движется только вперёд. Активные карточки упорядочены по конечным
срокам, каждая освобождает слот не позднее восьмого ответа. Старые повторы
занимают ограниченную долю потока, а их сроки после ответа переносятся вперёд.
Это обеспечивает продвижение по конечному набору при продолжении ответов,
включая сценарий постоянных провалов. Пропущенные/исключённые карточки не
попадают обратно через случайный fallback. Цикл заполнения ограничен длиной
словаря; рекурсии или ожидания календарного срока в адаптивном picker нет.

Полное состояние окна, сроки, история показов и курсор сохраняются в liveSession.
Восстановление продолжает ту же последовательность. Старые свободные сессии с
адаптивным picker мигрируют в равномерные; новая адаптивная включается явно.

## Проверка коэффициентов

Воспроизводимый прогон:

```
node --import tsx scripts/simulate-adaptive-window.ts
```

Число показов до первого появления каждого слова:

| Словарь | Все ответы верные | Все ответы неверные | Смешанный сценарий |
| --- | ---: | ---: | ---: |
| 100 слов | 510 | 1008 | 584 |
| 1000 слов | 5310 | 10608 | 6076 |

Смешанный сценарий: каждое седьмое слово всегда вызывает ошибку, у остальных
каждый шестой ответ ошибочный. Во всех шести прогонах максимум активных слов —
5, немедленных повторов — 0, словарь охвачен полностью. Это стресс-проверки
планировщика, а не прогноз реальной скорости обучения.

Модульные тесты также проверяют усиленный штраф, забывание, фильтры, малые/пустые
наборы, исключения/удаление, отсутствие блокировки на медленных ответах,
повторяемость подбора, сохранение и миграцию. Браузерные сценарии проверяют
переход окна, фиксированный режим, накопление статистики, перезагрузку и
мобильный ответ после подсказки.
